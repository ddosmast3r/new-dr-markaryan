## Как открыть после возвращения

Последний адрес просмотра: http://127.0.0.1:3111/#reviews . Это локальный сервер; после выхода он может остановиться.

Из корня проекта:

```sh
NEXT_DIST_DIR=.next-check npm start -- --hostname 127.0.0.1 --port 3111
```

Если сборка отсутствует или исходники изменились, сначала остановить сервер на 3111 и выполнить:

```sh
npm run check:build
```

Затем снова выполнить команду запуска. Для обычной разработки доступен `npm run dev`.

При продолжении сначала прочитать этот файл, посмотреть последний вариант отзывов и учесть новую обратную связь пользователя. Не начинать аудит заново и не возвращать отвергнутое оформление.
