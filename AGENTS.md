# Работа с сайтом

## Мобильная версия обязательна

При каждой правке интерфейса, стилей, видимого текста, изображений или навигации проверяй и исправляй мобильную версию в рамках той же задачи, даже если коммит и push не запрошены. Не жди отдельного напоминания пользователя.

- Перед завершением задачи запускай `npm run check:mobile:gate`. Команда сама собирает текущую рабочую копию и проверяет её на отдельном сервере; открытый просмотр на 3111 трогать не нужно.
- Просматривай скриншоты изменённых страниц при ширине 320 и 390/412 px. Проверяй читаемость и переносы заголовков, отступы, изображения, наложения шапки и кнопок. Дополнительно смотри изменённый блок на десктопе 1440 px.
- Для изменений меню, закреплённых элементов и окон проверяй касания, прокрутку, открытие и закрытие в портретном и горизонтальном положении 844 × 390. Используй мобильные контексты WebKit и Chromium с обычными анимациями, а не только суженное окно настольного браузера.
- Исправляй обнаруженные проблемы и повторяй затронутые проверки. Успешная сборка и отсутствие горизонтального скролла сами по себе не подтверждают качество мобильного дизайна. Не скрывай проблемные элементы ради прохождения проверки.
- Укажи в итоговом ответе, что было проверено; эмуляцию не называй проверкой на физических телефонах. Если проверка недоступна, прямо сообщи об этом и не утверждай, что она пройдена.

Хук `pre-push` запускает ту же проверку и останавливает отправку при ошибке. Скриншоты и JSON-отчёт лежат в каталоге `artifacts/mobile/run-*`, точный путь выводится после запуска. Хук проверяет текущую рабочую копию; визуальную оценку скриншотов выполняет агент.

Для первого запуска после `npm ci`: `npx playwright install chromium webkit`. На Linux для системных библиотек используется `npx playwright install --with-deps chromium webkit`.

## Сохранять решения пользователя

- Не добавлять цены и не менять географию без нового запроса пользователя.
- Сохранять зелёную палитру, фотографии и насыщенность дизайна при адаптации.
- Не откатывать чужие незакоммиченные изменения. Текущий контекст решений сохранён в `SESSION_HANDOFF_RU.md`.
