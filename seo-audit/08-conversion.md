## 1. Как сейчас проходит путь пациента

```
Яндекс («геморрой лечение пятигорск»)
 └─ /gemorroy — первый экран: H1 + абзац врача + [Записаться] [телефон]        ← УТП слабое, доказательств нет
     └─ Врач / Адрес / Часы                                                    ← нет цены, нет «что входит»
         └─ Симптомы → Стадии → Методы → Когда срочно → Восстановление         ← 5 секций без CTA (на десктопе — только шапка)
             └─ Диагностика → Смежные состояния → Видео
                 └─ «Всего четыре шага» → Карточка врача [Записаться]          ← первая кнопка в контенте
                     └─ FAQ [Задать свой вопрос] → Контакты → Другие направления
 Любая кнопка «Записаться» → модалка: MAX / Telegram / WhatsApp / ПроДокторов / звонок
     └─ уход во внешний мессенджер или на ПроДокторов → дальше путь не отслеживается
```

Где теряем пациентов:
1. **Первый экран услуги** не отвечает на три вопроса: «почему этот врач», «больно ли и надолго ли выпаду из жизни», «сколько стоит».
2. **Середина страницы.** Читатель «созрел» после блока «Методы лечения», а ближайшая кнопка записи на 3–4 экрана ниже. На мобильном есть FAB, но это та же модалка, в которой нужно сделать ещё один выбор.
3. **Модалка.** Пять равнозначных вариантов, и нет подсказки, *что писать*. Для стеснительного пациента пустое окно чата — главный барьер.
4. **После клика** сайт про пациента ничего не знает: цель засчитывается как «клик по WhatsApp», а была ли запись, не видно.

**Ограничение данных (P2, M).** Все цели отправляются только после «Принять» в cookie-баннере (`hasAnalyticsConsent`), поэтому Метрика видит лишь долю обращений. Для честной базы можно добавить серверные редиректы `/go/wa`, `/go/tg`, `/go/max`, `/go/call` со счётчиком в логе (без cookie и без ПДн, только агрегат по дню и странице). Это даёт полное число контактов для сравнения с Метрикой и с фактическими записями. Схему согласовать с политикой (COMPLIANCE п.3).

**Офлайн-конверсии (P3).** Клик ≠ запись. Минимум — раз в неделю вручную сверять число новых диалогов и записей с `contact_any`. Загрузку офлайн-конверсий по ClientID через мессенджер **не** делать: идентификатор окажется в переписке о здоровье.

## 12. Что нужно получить от врача (блокирует P1 и P2)

1. Цена первичного приёма; входит ли в неё аноскопия; длительность приёма.
2. Обезболивание и анестезия при операциях (геморрой, копчиковый ход, трещина); нужен ли стационар и сколько дней; выдаётся ли больничный и на какой срок.
3. Подтверждение формулировок «приём один на один», «можно написать без описания проблемы».
4. Оценка и число отзывов на ПроДокторов; ведётся ли там расписание (для виджета).
5. Тексты памяток (первый приём, после лечения) и логика теста симптомов.
6. Режим ответов вне рабочего времени.
