# Сайт доктора Маркаряна

Next.js и React.

## Локальный запуск

Откройте терминал в папке проекта. При первом запуске установите зависимости:

```sh
npm ci
```

Запуск сайта с автоматическим обновлением после правок:

```sh
npm run dev
```

Дождитесь сообщения `Ready` и откройте <http://127.0.0.1:3010>. Оставьте терминал открытым; для остановки нажмите Ctrl+C.

Dev использует `.next-dev`, production-сборка — `.next`. Проверки задают собственный `NEXT_DIST_DIR`, поэтому не перезаписывают сборку открытого просмотра.

Если запуск из ограниченной среды агента заканчивается `listen EPERM`, выполните `npm run dev` в обычном терминале macOS. Эта ошибка означает отказ в открытии порта; сервер при ней не запущен.

## Проверки

```sh
npm run lint
npm run check:mobile:gate
```

Для первого мобильного прогона после установки зависимостей нужны браузеры:

```sh
npx playwright install chromium webkit
```

Мобильный gate собирает рабочую копию и запускает отдельный сервер. Скриншоты и отчёт сохраняются в `artifacts/mobile/run-*`.
