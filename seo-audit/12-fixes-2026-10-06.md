# Исправления после SEO-аудита — 6 октября 2026

Изменения находятся в рабочей копии, коммит и публикация не выполнялись. Цены и география не менялись; фотографии, зелёная палитра и видеофон сохранены.

## Что исправлено

- `next.config.mjs`: постоянный редирект www на основной домен с сохранением пути и параметров; старые адреса на www сразу ведут на актуальные страницы.
- `app/sitemap.js`: удалена недостоверная дата lastmod, которая раньше обновлялась при каждой сборке.
- `app/not-found.jsx`: собственные метаданные 404, без унаследованного canonical главной и конфликтующего index; ответ 404 и noindex сохранены.
- `lib/schema.js`, `lib/content.js`: IndividualPhysician и practicesAt вместо неподходящего worksFor; услуги размечены как MedicalTherapy с названиями лечения.
- `app/kontakty/page.jsx`: устранён повтор H1 в H2.
- `components/Header.jsx`, `components/HeaderClient.jsx`: данные навигации передаются серверным компонентом, большие тексты страниц больше не попадают в клиентский пакет через импорт навигации.
- `components/Hero.jsx`, `components/PageHero.jsx`, `components/HeroMedia.jsx`: уточнены приоритеты и размеры изображений; видео запускается после загрузки страницы, неактивные ролики не загружаются заранее. Подготовлены облегчённые копии фона в `public/video/hero/`, оригиналы для просмотра сохранены. Скрипт подготовки: `scripts/prepare-hero-videos.mjs`.
- `app/layout.jsx`, `styles/fonts.css`, `public/fonts/`: те же шрифты размещены локально вместе с лицензиями; сборка больше не зависит от загрузки Google Fonts. Для файлов шрифтов задан длительный immutable-кеш.
- Добавлена команда `npm run check:seo` и проверки метаданных, sitemap, Schema.org, редиректов и 404.

## Проверки и их границы

До двух последних мобильных правок прошли 195/195 SEO-проверок, 551/551 общих проверок сайта и 316/316 проверок мобильных сценариев. Успешный мобильный прогон: `artifacts/mobile/run-tliNfR/`. Проверялась эмуляция WebKit и Chromium с касаниями, обычными анимациями, портретными размерами 320/390/412 px и горизонтальным 844 × 390; это не физические телефоны. Просмотрены скриншоты страниц и изменённых блоков, включая десктоп 1440 px. Валидатор Schema.org не обнаружил ошибок в проверенной разметке страницы геморроя с общими сущностями врача и клиники. Отдельно проверены запуск, смена и остановка фонового видео, reduced motion и загрузка шрифтов.

По результатам визуального просмотра внесены ещё две правки:

- В H1 колоноскопии длинное слово «Видеоколоноскопия» заменено на «Колоноскопия», чтобы убрать одиночную букву на следующей строке при ширине 320 px. Описание видеопроцедуры и город сохранены.
- Плавающая кнопка записи учитывает остальные кнопки записи и раньше скрывается при их появлении, чтобы исключить наложение. В мобильный скрипт добавлена проверка пересечений.

Отчёт: `artifacts/mobile/run-yfXOVT/gate.json`. Поэтому мобильная проверка последней рабочей копии **не завершена**. При восстановлении возможности запускать серверы повторить gate и посмотреть заголовок колоноскопии и поведение плавающей кнопки на 320/390 px, в горизонтальном положении и на десктопе.

Подробные временные результаты SEO, общей проверки, видео и Lighthouse: `/private/tmp/edjo-seo-fixes-2026-10-06/`. Этот каталог может быть очищен системой.

## Локальный запуск

Первые попытки запуска на 3002 и 3010 завершились `listen EPERM`. Затем по просьбе пользователя обычная команда dev настроена на порт 3010; dev и production используют разные каталоги сборки. Команда из корня проекта:

```sh
npm run dev
```

Этот запуск дошёл до `Ready`, `lsof` подтвердил процесс node, слушающий `127.0.0.1:3010`. Сервер оставлен работающим. HTTP-ответ из ограниченной среды подтвердить не удалось: curl не соединяется с локальными серверами. ESLint прошёл без предупреждений; повторный мобильный gate собрал сайт, но остановился с `listen EPERM` при открытии отдельного тестового порта (`artifacts/mobile/run-b8Tbxr/gate.json`).

Инструкция запуска: `README.md`. Dev-каталог `.next-dev` исключён из Git и ESLint, явный `NEXT_DIST_DIR` сохранён для проверок. Просмотр на 3111 не перезапускался. Ранее созданный просмотр на 3112 использует сборку `.next-mobile-seo-localfonts`, без последних двух правок интерфейса; его доступность после ограничения среды не подтверждена.
