Найдена и исправлена дополнительная ошибка копирования: при закрытии окна до отказа браузера в доступе к буферу обмена код пытался выделить уже удалённый текст и выбрасывал `TypeError`. Добавлены проверки успешного копирования, отказа, отсутствия Clipboard API и отложенного отказа после закрытия. Рабочие зависимости повторно проверены: известных уязвимостей нет. Пять предупреждений в цепочке инструментов ESLint остаются; подробности ниже.

Дополнение после жалобы на мобильную версию: устранено просвечивание текста через закреплённую шапку и навигацию; кнопка закрытия записи закреплена вне прокручиваемого содержимого. Добавлена проверка мобильных контекстов с касаниями и анимациями (`npm run check:mobile`): 196 проверок прошли в WebKit и Chromium. Повторная проверка сценариев записи: 218/218. Сборка и ESLint прошли. Это эмуляция iPhone/Android, а не проверка на физических устройствах. Подробности сохранены в `SESSION_HANDOFF_RU.md`.

Проверена локальная production-сборка. Основная разработка завершена; найденные функциональные ошибки исправлены. Цены, география и последнее оформление отзывов не менялись. На действующий сайт изменения пока не опубликованы.

## Исправлено

1. **Шапка при переходах.** Отложенный обработчик прокрутки/изменения размеров обращался к уже удалённому элементу и вызывал JavaScript-ошибку. Обработчик теперь проверяет, что элементы ещё находятся в документе.
2. **Мобильное меню с клавиатуры.** После открытия фокус пропускал ссылки меню и переходил к содержимому страницы. Теперь он переходит в меню; Escape возвращает его на кнопку, а выход фокуса закрывает меню.
3. **Возврат фокуса в WebKit.** После закрытия видео фокус терялся, поскольку WebKit не фокусирует кнопку при обычном клике. Сохраняется конкретная кнопка запуска. Для окна записи также обеспечен надёжный возврат к исходной кнопке.
4. **Яндекс Метрика.** Несколько обращений до загрузки SDK повторно отправляли `init`; переходы Next.js между страницами не отправляли просмотры. Инициализация теперь однократная, первый и последующие просмотры отправляются явно, повтор пути/query не даёт дубля. Согласие на аналитику по-прежнему обязательно. Основание: [документация Метрики для SPA](https://yandex.ru/support/metrica/ru/code/counter-spa-setup).
5. **Недоступная страница.** Вместо стандартной английской ошибки добавлена русская страница 404 с кнопкой возврата на главную.
6. **Повтор описания видео.** Убрано дублирование подписи постера для вспомогательных технологий; название остаётся в подписи и доступном имени кнопки.
7. **Зависимости.** Next.js обновлён с 15.5.19 до 15.5.27, ESLint-конфигурация — до той же версии. Обновлены Sharp до 0.35.5 и PostCSS до 8.5.28, а также доступные исправления зависимостей разработки. PostCSS переопределён в `overrides`, поскольку Next.js сохраняет старую точную версию. [Релиз Next.js 15.5.27](https://github.com/vercel/next.js/releases/tag/v15.5.27), [описание исправленной уязвимости обработки изображений](https://github.com/vercel/next.js/security/advisories/GHSA-2xp9-vwfh-vxw4).
8. **Копирование сообщения.** Отложенный отказ в доступе к буферу обмена после закрытия записи больше не вызывает ошибку. Если окно открыто, остаётся выделение текста для ручного копирования; если закрыто, работа с удалённым элементом прекращается.

## Границы проверки и оставшиеся замечания

- **Внешние площадки:** часть запросов к ПроДокторов, Wiley и СМ-Клинике получила 401/403; WhatsApp и Telegram недоступны из среды автоматического запроса. Это не установленные битые ссылки. Адреса сохранены, факт успешной записи или доставки сообщения внешними сервисами не проверен. Сообщения никому не отправлялись.
- **Инструменты разработки:** полный `npm audit` показывает пять предупреждений high в одной цепочке `eslint-config-next → @next/eslint-plugin-next → fast-glob → micromatch → braces`. Это зависимости проверки кода; `npm audit --omit=dev` чистый. Предлагаемый автоматический «fix» откатывает ESLint-конфигурацию на другую основную версию; такой откат не применялся. [Advisory braces](https://github.com/advisories/GHSA-vfj7-8cjw-p6xm).
- **Сборочные предупреждения:** Next.js сообщает о нескольких lockfile выше папки проекта и о неуказанном типе модуля для JS-файлов. Они не мешают сборке; чужие файлы вне проекта не менялись.
- **Среда публикации:** обновлённый Sharp требует Node.js не ниже 20.9. Локальная проверка выполнена на Node.js 26.7.0. Настройки и версия Node.js удалённого сервера в эту проверку не входили.
- **Содержание:** медицинские и юридические тексты не считаются одобренными врачом/юристом вследствие технической проверки. Сведения о публикации и границы подтверждения описаны в `IMPLEMENTATION_2026-10-03_RU.md`.
- WebKit проверялся как браузерный движок, а не на физическом iPhone. Автоматический аудит доступности не заменяет полную ручную проверку со скринридером. Нагрузочный тест и полный тест на проникновение не проводились.

## Повторный запуск

При работающей production-сборке на `http://127.0.0.1:3111`:

```sh
npm run check:site
BROWSER=webkit npm run check:site
npm run check:journeys
npm run check:mobile
npm run check:analytics -- http://127.0.0.1:3111
npm audit --omit=dev
```

Для WebKit нужен `npx playwright install webkit`. Флаг `SCREENSHOTS=1` у `check:site` сохраняет полные снимки страниц. Отчёты браузеров: `/private/tmp/edjo-full-review-chromium/site-checks.json` и `/private/tmp/edjo-full-review-webkit/site-checks.json`. Первичные снимки и результаты проверки внешних ссылок: `/private/tmp/edjo-full-review/`.

Результаты повторной проверки: `/private/tmp/edjo-recheck-chromium/`, `/private/tmp/edjo-recheck-webkit/`, `/private/tmp/edjo-recheck-mobile/` и `/private/tmp/edjo-recheck-journeys/`. Полный повторный аудит зависимостей: `/private/tmp/edjo-recheck-dependencies.json`.

Тестовые обращения к аналитическим SDK подменяются; проверяется интеграция сайта без засорения реальных счётчиков. Число 1578 — количество автоматических утверждений в сценариях, а не количество уникальных функций сайта.
