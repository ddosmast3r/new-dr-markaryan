## 1. Нужно от врача (без этого контент не сдвинуть)

1. Вычитать черновики страниц услуг и FAQ.
2. **Где реально принимает.** Каталоги показывают Ессентуки и Иноземцево, на сайте только Калинина, 90А. По ответу — добавить адреса или чистить каталоги.
3. Единые стаж, категория, курсы, аккредитация, членство в обществах. Подтвердить «5000+ операций» и публикации.
4. Цены «от» по каждой услуге, платно/ОМС, наркоз/седация, стационар, больничный.
5. Методы, которые он реально делает: лазер, кольца, склеротерапия, ДГАЛ, SiLaC, полипэктомия, ректороманоскопия. Кто делает ФГДС.
6. Своя схема подготовки к колоноскопии и гастроскопии.
7. Съёмка ~10 коротких роликов «Врач отвечает».

## 2. Быстрые технические правки (P1–P2, ~2–3 дня в сумме)

- 301 `www.dr-markaryan.ru` → основной домен, HTTP/2, HSTS, Brotli, долгий кэш для `public/` — nginx (01, 10).
- `robots.txt`: `Clean-param` для utm/yclid/ysclid, явные правила для AI-ботов. Не заводить отдельный блок `User-agent: Yandex` (01, 09).
- Честный `lastmod` в sitemap, IndexNow после деплоя, Bing Webmaster (09).
- Схема: `worksFor` → `IndividualPhysician` + `practicesAt`; у клиники телефон клиники, лицензия, ОГРН; добавить `WebSite`, `Person` с образованием, `MedicalWebPage` с автором и датой проверки (02, 05).
- Убрать общие FAQ («Это больно?», «Сколько стоит») со страниц услуг — оставить на `/voprosy` (01, 02, 07).
- Хлебные крошки: Главная → Лечение → услуга (01).
- «Проктолог Пятигорск» закрепить за H1 главной; убрать дубль H2 из сквозного блока контактов (01).
- Скорость:
  - перекодировать фоновые ролики (−95%) и не грузить видео на планшетах;
  - навигацию считать на сервере (−67% JS);
  - убрать preload JetBrains Mono;
  - `fetchPriority` для LCP-картинки;
  - отложенный старт Метрики (10).
