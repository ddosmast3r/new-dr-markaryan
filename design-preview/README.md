# Концепция «Спокойный разговор»

Отдельный интерактивный макет главной страницы сайта Эдуарда Маркаряна. Создан для обсуждения дизайна; страницы приложения Next.js не изменены. Превью не входит в `app` или `public` и не добавляет маршрут к действующему сайту.

Идея: спокойный личный сайт врача. Выразительность создают крупная типографика, фотографии и чередование композиций. На первом экране человек сразу видит врача, специальность, город и действие для записи.

- Светлый фон `#f7f8f3`, текст `#263d32`, основной зелёный `#305442`, мягкий акцент `#d3e5b6`.
- Один шрифт Golos Text из уже используемых проектом файлов; фотографии и логотип из `public`.
- Направления представлены списком и отдельным блоком диагностики. О враче — фотография с кратким рассказом. Первый приём — последовательность шагов. Вопросы — раскрывающиеся ответы. Запись завершает страницу контрастным зелёным блоком.
- На телефоне основное действие находится перед большим портретом. Меню работает по кнопке и Escape. Запись открывается в нативном диалоге с внутренней прокруткой и восстановлением фокуса.

Для просмотра из корня репозитория:

```sh
python3 -m http.server 3102 --bind 127.0.0.1
```

Открыть http://127.0.0.1:3102/design-preview/ . Можно также открыть `index.html` напрямую. Файлы шрифтов включены в папку, изображения берутся из соседней папки `public`.

Ссылки на направления, документы и сервисы записи ведут на действующие страницы. Сам макет не отправляет аналитику и не собирает данные.

Дизайн проверен в Chromium на ширинах 320, 390, 768, 1024 и 1440 px, включая окно записи на 320×568. Скриншоты первого экрана и полной страницы находятся в `screenshots`.

Для переноса в приложение отдельно потребуются компоненты Next.js, существующая аналитика/согласие cookie, финальные метаданные и подтверждение редакционных формулировок. Тексты макета — предложение для обсуждения. Цена, второй адрес и новые сведения о квалификации не добавлялись.
