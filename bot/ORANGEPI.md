# Размещение на Orange Pi

## Состояние носителя: требуется восстановление

Владелец сообщил, что карта поддельная и реальная ёмкость может составлять
около 5 ГБ. Показания контроллера 500 ГБ и `df` не подтверждают физическую ёмкость.
Раздел и ext4 были ошибочно расширены; повторно `growpart` не выполнять.
Бот остановлен, корень переведён в read-only, пишущие прикладные службы
остановлены для защиты данных. Возвращать старые границы раздела до офлайн
уменьшения файловой системы нельзя. Перед восстановлением нужны резервные
копии и загрузка с другого проверенного носителя либо работа через картридер.

Приоритет — восстановление прежней файловой системы/переезд на настоящий
носитель. Локальный Telegram API и большие загрузки до этого не включать.

Хост: `root@192.168.0.50`, `orangepi3-lts`, Armbian/Debian 13, aarch64.
Бот: [@drmarkaryanbot](https://t.me/drmarkaryanbot).

- Код: `/opt/dr-markaryan-video-bot`.
- Отдельный Node.js 24: `/opt/dr-markaryan-node24/bin/node`; системный Node 20
  и окружение других приложений не меняются.
- Системный пользователь: `drmarkbot`.
- Секреты: `/etc/dr-markaryan/video-bot.env`, root, права `0600`.
- SQLite, очередь и медиа: `/var/lib/dr-markaryan/videos`.
- Служба: `dr-markaryan-video-bot.service`, автозапуск через systemd.
- Лимиты службы: одно ядро, 900 МБ памяти, пониженный приоритет CPU.

Проверка: `systemctl status dr-markaryan-video-bot` и
`journalctl -u dr-markaryan-video-bot --no-pager -n 30`.
После изменения закрытого файла окружения: `systemctl restart dr-markaryan-video-bot`.
Не выводить содержимое файла окружения в логи или переписку.

## Первоначальный режим

До настройки реквизитов приложения используется облачный Telegram API: лимит 20 МБ.
Участники могут войти через закрытую ссылку: `mint-invite.mjs 3 7` выдаёт три
места на семь дней, ID сохраняются автоматически после входа. Обычный `/start`
без приглашения управления не открывает. При необходимости можно продолжать
использовать `TELEGRAM_ALLOWED_USER_IDS` в закрытом файле окружения.
Публикация на сайт использует отдельный SSH-ключ в
`/var/lib/dr-markaryan/videos/site-access/`. Пользователь на сервере сайта —
`drmarkpublish`; ключ допускает только протокол передачи видео, без shell и sudo.

Сайт работает на отдельном сервере `217.149.30.67`. Приёмник:
`/opt/dr-markaryan-video-receiver/site-receiver.py`, каталог видео:
`/var/lib/dr-markaryan/videos`. На сайте используется отдельный Node.js 24
в `/opt/dr-markaryan-node24`, системный Node.js не заменяется.
Публикации, правки и снятие передаются с подтверждением версии; ссылки в
Telegram отправляются только после успешного ответа сайта.

Локальный Telegram Bot API собирается из официального репозитория tdlib на
ARM64 runner, бинарник устанавливается в `/opt/telegram-bot-api/bin/`.
Шаблон службы — `telegram-bot-api.service.example`, закрытый файл приложения —
`/etc/dr-markaryan/telegram-api.env` с `TELEGRAM_API_ID` и `TELEGRAM_API_HASH`.
После установки и проверки реквизитов `python3 bot/migrate-local-api.py`
выполняет выход из облачного API, проверяет локальный, сохраняет настройки
публикации и доступа и поднимает лимит до 2 000 МБ. При сбое после выхода из
облака повторный запуск продолжает миграцию, не открывая вторую сессию.

Исходная разметка карты перед расширением сохранена в
`/var/backups/dr-markaryan/mmcblk0-before-growth.sfdisk`; начало раздела — сектор
8192. Размер и свободное место проверять через `lsblk` и `df -h /`.

Резервные копии: каталог данных и закрытый файл окружения. Копии с токеном хранить
вне Git. Инструкции по согласованному копированию SQLite — в README бота.
